# Squidpy spatial-analysis seed

Squidpy is a Python framework for spatial omics analysis. It represents spatial relationships with
neighborhood graphs and supports analyses of tissue organization, spatial statistics, molecular
features, and image-derived information. Method selection and neighborhood construction parameters
must remain visible because they affect biological interpretation.

Source basis: Palla et al., Nature Methods 19, 171–178 (2022), DOI 10.1038/s41592-021-01358-2.
